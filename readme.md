# dev-dark

a dark theme for mailspring based on the rezzt.dev visual system and the [nexus dark palette](https://github.com/iampankajghosh/nexus-dark/blob/main/themes/nexus-dark.json).

## install

- download or clone this repository.
- in mailspring, open `install new theme...` and select the folder containing `package.json`.
- open `change theme...` and select `dev-dark`.

## design

- use poppins across the application interface.
- use `#0a0a0a` for the main surfaces and `#262626` for menus and fields.
- use `#404040` for selected rows and a subtle white border for separators.

received html emails retain the sender's formatting. native window elements follow the operating system theme.

## files

- `styles/` contains the theme's less files.
- `assets/fonts/` contains the poppins fonts and their license.
