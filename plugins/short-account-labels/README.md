# short account labels

A Mailspring plugin that displays only the part before `@` for email-address section headings in the left account sidebar. It does not rename accounts or change message data. Disable or remove the plugin to restore the original labels.

## install

1. In Mailspring, choose **Developer → Install a Package Manually...**.
2. Select this `short-account-labels` folder.
3. Restart Mailspring if requested.

For example, `contacto@rezzt.dev` is shown as `contacto`. Labels that are not email addresses are left unchanged.
