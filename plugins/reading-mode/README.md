# READING MODE

modo temporal de lectura para la vista de conversación de mailspring.

## INSTALACION

en mailspring, abre `developer → install a package manually...` y selecciona
la carpeta `plugins/reading-mode`. reinicia la aplicación si se solicita.

## USO

abre una conversación y pulsa `modo lectura`, encima de los mensajes, o usa
`ctrl/cmd+mayús+r`. el modo oculta las barras laterales, reduce la presencia
visual de los controles y amplía el espacio de lectura. el segundo botón cambia
entre espaciado cómodo y compacto. al salir se restaura la disposición normal.

## LIMITACIONES Y PRIVACIDAD

el estado es temporal y se pierde al reiniciar o desactivar el plugin. el atajo
solo actúa cuando hay una conversación abierta y el foco no está en un campo
editable. el plugin no lee ni modifica el contenido de los mensajes y no envía
datos fuera de mailspring.
